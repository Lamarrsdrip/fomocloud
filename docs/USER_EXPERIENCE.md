# Plain-English user experience

The user app avoids developer jargon.

Instead of:
- RPC unavailable → "We temporarily lost our market connection. New buys are paused."
- Slippage exceeded → "Price moved too much before we could buy, so we skipped it."
- Permission expired → "Your trading permission expired. Reconnect to resume."
- No route → "We couldn't find a safe way to sell this token, so we did not buy it."
- Max exposure → "You've reached the amount you allowed FomoCloud to have in open trades."
- Confirmation pending → "Trade sent. Waiting for the blockchain to confirm it."

Main tabs:
- Home
- Discover
- Activity
- Positions
- Profile

The user never needs to see an infrastructure dashboard.

The Home screen should answer five things immediately:
1. How much is my wallet/trading allocation worth?
2. Is FomoCloud active?
3. Who am I copying?
4. What trades are open?
5. What did the bot do recently, and why?

Every trade receipt explains:
- who triggered it
- why FomoCloud entered
- why it skipped if it did not enter
- entry amount
- exact transaction
- fees
- profit targets already taken
- runner status
- current protection
- why the final exit occurred

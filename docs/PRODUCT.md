# Product principles

- Consumer app, not developer dashboard.
- Connect, follow, set limits, activate.
- Every financial number has provenance.
- No fake "live" feed.
- Skipping a dangerous/late trade is a product feature.
- Users can understand why a trade was copied or skipped.
- Users can pause new entries immediately.
- Every confirmed live order links to a chain explorer in production.
- Performance claims use meaningful sample sizes and clear time ranges.
